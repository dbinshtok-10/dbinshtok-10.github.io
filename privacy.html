Privacy Policy

Last updated: October 21, 2026

Review Bot is a private, personal tool used only by its owner. This policy explains how it handles data.

Data the tool accesses

With the owner's permission, the tool accesses the owner's Google Drive and Google Sheets in order to read documents in one folder chosen by the owner, create summary documents, and add rows to an index spreadsheet owned by the owner.

How the data is used

Document contents are sent to the Google Gemini API to produce summaries. Summaries are saved back to the owner's own Google Drive and sent to the owner's own Telegram account. The data is used for no other purpose.

Sharing

The tool does not sell, share, or transfer data to any third party other than the services named above, which are needed to produce and deliver the summaries. No data is used for advertising.

Storage

The tool keeps only a small local record of which files have already been processed, on a device controlled by the owner. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
